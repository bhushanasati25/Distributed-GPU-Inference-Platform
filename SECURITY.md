# Security Policy

## Supported Versions

| Version | Supported          |
| :--- | :--- |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this platform seriously. If you discover a vulnerability in the Go routing engine, Kubernetes manifests, or data pipelines, please report it privately:

1. **Email**: Send vulnerability reports to `bhushanasati25@gmail.com`.
2. **Details to Include**:
   - Description of the issue and potential impact.
   - Minimal reproduction steps or proof-of-concept payload.
   - Any suggested remediations or workarounds.
3. **Response Time**: We will acknowledge receipt within 48 hours and provide regular updates until a patch is issued.
